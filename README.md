# ml-notebooks

Selected notebooks from coursework and course projects, grouped by topic. Each project folder has its own README with the problem, method, results and how to run it. Data and large files are not tracked.

| Project | Topic | Summary |
|---|---|---|
| [nlp/clickbait-spoiling](nlp/clickbait-spoiling) | NLP | Classify the spoiler type of a clickbait post (SemEval 2023 Task 5) with fine-tuned transformers. Best test balanced accuracy 0.695. |
| [computer-vision/spine-segmentation](computer-vision/spine-segmentation) | Computer vision | Segment individual vertebrae from a frontal spine X-ray with classical image processing (group project). |

My thesis work on recommendation systems is in a separate repository: [Balancing-Novelty-and-Accuracy-in-Recommendation](https://github.com/Riririll/Balancing-Novelty-and-Accuracy-in-Recommendation).
